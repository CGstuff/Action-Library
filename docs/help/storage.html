Storage

Where your animations live, how to keep more than one library, and how to share one with other people.

The library folder

Everything lives in one folder you choose. Inside it:

FolderWhat's in it
library/actions/Your animations — one folder each.
library/poses/Your poses.
_versions/Older versions.
.meta/The index, review notes and drawings.
.deleted/, .trash/Archive and Trash (Studio mode).
.queue/Messages between Blender and the app.

Each animation's folder holds its .blend, a thumbnail, a preview video, and a small .json of its metadata. Plain files, no proprietary container — copy the library folder and you've backed everything up, including every version.

Using more than one library

The dropdown at the top-left of the header is the library picker. It lists the libraries you've used, most recent first, and switching is immediate — the whole app re-points at the one you pick, and Blender follows within a couple of seconds without you touching anything.

Adding a library

Pick Browse for another folder… at the bottom of the dropdown. Choose an existing library to add it to the list, or an empty folder to start a new, empty one — Action Library builds everything it needs inside it. Once you've used a library it's remembered, so you only browse for it once.

Forgetting a library

Right-click the picker and choose Forget. This only removes it from the dropdown — nothing is deleted, the folder and every animation in it stay exactly as they are, and you can add it back with Browse.

You can't forget the library you're currently using; it would just reappear.

Unavailable libraries

A library on a network drive you can't currently reach — off the VPN, drive unplugged — is shown as unavailable and can't be selected. It stays in the list rather than disappearing, because it isn't gone, you just can't see it right now.

The list of libraries is kept on your machine, not in any library. It has to be — a library can't hold the list of libraries, since whichever one you're in only knows about itself.

Sharing a library

Put the library folder on a shared drive and point everyone at the same path. Everyone captures into it and sees everyone else's work.

What's shared and what isn't

Shared by everyoneYours alone
Animations, poses, versionsYour identity (your name and colour)
Tags, folders, favoritesYour Recent list
Status, review notes, drawingsWhich library you're pointed at
Window layout, view settings

That split is deliberate. Identity is per machine so two people on one library don't overwrite each other, and Recent is per machine because "what I was just looking at" is about you, not about the library.

Expectations on a network drive

  • A colleague's capture takes a few seconds to appear.
  • Use Studio mode so deletes go through Archive rather than being instant.
  • Everyone should run the same version of Action Library.
  • If something seems stale, press refresh.
Sharing works over a normal mapped drive or network share. It is not designed for Dropbox, Google Drive or OneDrive — those sync files in the background on their own schedule and will fight the app's index. If you need a shared library, use a real network share.

Changing where the library lives

To move an existing library: close Action Library, copy the folder wherever you want it, reopen, and point the picker at the new location with Browse. The app doesn't move files for you — deliberately, because moving gigabytes of animation is a job for your file manager, not a button that might fail halfway.

You can also change it from Settings › Storage Locations, which does the same thing as the picker.

Backups

Copy the library folder. That's it — animations, versions, notes, drawings and the index all live inside it.

Action Library also keeps its own database backups (from Settings › Maintenance), but those only cover the index, not your animation files. They're a safety net for the app, not a backup of your work.
