Settings

The gear icon, top-right. Seven pages down the left-hand side.

Storage Locations

Where your library lives, and where Action Library keeps its own files. Change Library Location… does the same as the picker in the header — see Storage.

This page also holds Allow permanent deletion, off by default. While it's off, nothing can be destroyed permanently — see Archive & delete.

Blender Integration

The link between the app and Blender. Set the path to your Blender executable, Verify it, and Install Addon.

Close Blender before installing, and reinstall after every Action Library update — the two halves are versioned together. The full story is on the Install & update page, and there's a button on this tab that opens it.

Port is how the app talks to the addon. It defaults to 9876 and must match the port in the addon's own preferences in Blender. Only change it if something else on your machine wants that port.

Appearance

Themes. Pick one, or build your own in the theme editor — colours for every part of the interface, including the card backgrounds.

Backup

Shows where the database lives, and lets you export and import your library.

Export is a way to move or share a library as a single file. For an actual backup, copy the library folder — see Backups.

Maintenance

Database health. Most people never need this page — it's here for when something has gone wrong.

  • Schema version and Upgrade — the database's format version.
  • Run Integrity Check — verifies the database isn't damaged.
  • Optimize Database — reclaims unused space.
  • View Backups — automatic database backups, and a button to make one now.
  • Rebuild Database — clears the index and re-imports every animation by re-scanning your library folder. Your animation files aren't touched. This is the "everything looks wrong" button: since the files on disk are the truth and the database is only an index, rebuilding it is safe.
  • Library Repair — one-time repairs for older libraries. Both are harmless no-ops on a healthy library.
  • Activity Log — a record of recent actions on review notes.

Identity

Your name and colour, used to attribute review notes and drawings. Stored on your machine, not in the library — so everyone sharing a library keeps their own, and nobody overwrites anyone else's. Click the identity pill in the header to come straight here.

Naming templates

Action Library can build names from a template instead of free text, so a whole team names things the same way — something like {character}_{action}_v{version:03}. When a template is configured, Blender's capture panel shows fields to fill rather than a name box, and the app's rename dialog does the same.

This is a studio nicety. Working alone, plain descriptive names are fine — search covers names, tags, descriptions and rig type either way.
