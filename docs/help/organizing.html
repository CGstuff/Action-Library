Organizing

Folders, tags, favorites, renaming and metadata — the work that makes a library findable instead of just large.

Folders

Create a folder with the + button in the header or by right-clicking in the tree. Drag cards onto it to put them in. Drag folders onto each other to nest them; drag one onto empty space to move it back to the top level.

An animation can be in many folders

This is the important one, and it's deliberate. A run is genuinely Locomotion and GameDev and Show01 at the same time — so drag it into all three and it lives in all three. Folders here aren't a filing cabinet where a thing can only be in one drawer.

  • Dragging a card into a folder adds it there. It stays wherever else it already is.
  • Dragging moves nothing on disk. Your files never move; a folder is a way of looking at your library, not a place your files live.
  • To take an animation out of one folder, use Remove from folder on its right-click menu. It stays in the others.

Renaming and deleting folders

Right-click a folder to rename it. Renaming is safe: what's in a folder doesn't depend on what the folder is called, so nothing is lost and nothing needs re-filing. Subfolders come along with it.

Deleting a folder asks first, and tells you what it will affect. Your animations are not deleted — they, their versions and their files all stay exactly as they are, and anything that was only in that folder goes back to Home.

Each folder also puts its name on its animations as a tag, so you can find them by searching for the folder. Delete the folder and that tag goes too — the folder owns it. Tags you added yourself are never touched.

Folder icons

Right-click a folder to give it an icon from a set of presets. Purely cosmetic, genuinely useful once you have a dozen folders. Icons follow their folder when you rename or move it.

Tags

Tags are free-form labels: combat, wip, client_approved, needs_polish. They're searchable, and they drive the tag filter.

Tags come from three places: you set them when you capture, from the Blender panel; each folder adds its own name to whatever's in it; and you can add your own in the app. Turn on edit mode in the header, and the metadata panel lets you add a tag with + and remove one with the × on its badge. The bulk toolbar adds and removes tags across many animations at once.

Capitalisation doesn't create duplicates. Type combat when the library already has Combat and you get the existing tag, not a second one — whichever spelling was used first is the one that sticks. Same for folder names: you can't have Combat and combat side by side.

Favorites

Click the star on a card, or use its right-click menu. Starred animations show up in the Favorites folder. It's the fastest thing in the app — use it for the twenty animations you actually reach for.

Renaming

Select an animation and press Rename in the metadata panel. Action Library renames the folder and every file inside it to match, and updates its records — so the rename survives restarting, and nothing goes missing.

Which dialog you get depends on the animation:

  • Simple rename — edit the base name. The version suffix is managed for you.
  • Template rename — if the animation was named from a studio template, you get the individual fields instead of one text box, and can apply the rename to all versions at once.
Renaming is safe. It's a real rename on disk and in the database together, not a display name papering over the old one.

Metadata

The right-hand panel shows everything known about the selected animation:

FieldWhere it comes from
NameSet at capture; changeable with Rename.
DescriptionSet at capture.
TagsCapture, or folders. Removable in edit mode.
Rig typeDetected at capture. Drives the rig filter and the compatibility check.
Frame range / durationRecorded at capture.
AuthorWhoever captured it.
StatusYou set it — see Review.
FilesWhere it lives on disk.
Description and author are set at capture and displayed read-only in the app. If a description matters, write it in Blender's capture panel while you still remember what it was for.

Bulk edits

Turn on edit mode in the header and select several cards (Ctrl+click, or Shift+click for a range). The bulk toolbar appears, and can:

  • add a tag to everything selected, or remove one,
  • add the selection to a folder,
  • set a custom thumbnail gradient — a two-colour background behind the cards. Colour-coding a group is a quick way to make it findable by eye,
  • archive or delete the selection — see Archive & delete.

What's actually worth doing

The library only pays you back if you can find things. In rough order of value for effort:

  1. Name things properly at capture. Everything else is a workaround for not having done this.
  2. Star your top twenty. Ten seconds, used daily.
  3. Tag by context — the character, the shot, the project.
  4. Write descriptions for anything unusual. Search reads them.
  5. Folders whenever you like. They're a view onto your library, not a place your files live — so they're cheap to change your mind about, and an animation can sit in as many as make sense.
