Install & update

Action Library is two pieces: the desktop app (where you browse your animations) and the Blender addon (which captures animations out of Blender and applies them back). The app installs the addon for you — you don't download it separately.

Close Blender before installing. See Why Blender must be closed — this is the single most common reason an install appears to "not work".

Installing the Blender addon

Everything happens inside Action Library:

  1. Close Blender completely.
  2. In Action Library, open Settings (the gear icon, top right).
  3. Go to the Blender Integration tab.
  4. Set Path to your Blender executable — on Windows that's blender.exe, typically under C:\Program Files\Blender Foundation\Blender 4.5\blender.exe. Click Verify; you should see a green tick and the detected version.
  5. Click Install Addon.
  6. Start Blender.

That's it. You do not need to enable the addon by hand.

What the installer actually does

Clicking Install launches Blender once, invisibly, in the background, and has it do four things:

  • Install the addon.
  • Enable it — so it's already ticked in Preferences when you look.
  • Point it at your Action Library storage folder, so the addon and the app are talking about the same library from the first launch.
  • Save your Blender preferences, so all of the above survives a restart.

Because it launches Blender itself, Blender must be closed while it runs.

Why Blender must be closed

The installer works by starting its own background copy of Blender and saving preferences from it. If you already have Blender open at the same time:

  • Your open Blender will not see the addon — it read its preferences when it started, and it won't re-read them.
  • Worse, that open Blender has its own copy of the preferences in memory. When it writes them back, it can overwrite what the installer just saved — leaving you with no addon and no explanation.

So: close Blender, install, then start Blender. If you forget, just close Blender and run the install again.

Checking it worked

Start Blender and look in the 3D Viewport. Press N to open the sidebar if it isn't showing, and choose the Animation tab down the right-hand edge. You should see an Animation Library panel, with Capture and Extra panels below it.

The sidebar tab is called Animation — not "Action Library". The panel inside that tab is the Action Library one. If you're hunting for a tab with the app's name, you won't find it.

The panel shows the library path it's using. That should match the storage folder shown in Action Library under Settings › Storage Locations. If it does, the two halves are linked and you're done.

Confirming from the app side

Back in Action Library, Settings › Blender Integration shows the addon's status once a Blender path is set:

Reinstalling and updating

Whenever you update Action Library, reinstall the addon. The app and the addon are one product in two halves and they're versioned together — an old addon talking to a new app is the source of most odd behaviour.

It's the same button, which renames itself to tell you what it will do:

  • Install Addon — nothing is installed yet.
  • Update Addon (v1.5.1 Available) — an older addon is installed.
  • Re-install Addon — the addon already matches the app; pressing it is harmless and is the first thing to try if something's misbehaving.

The steps are identical to a first install: close Blender, press the button, start Blender. Reinstalling overwrites the addon in place — it does not touch your library, your animations, or any of your settings.

Reinstalling is safe and takes seconds. It is never the wrong thing to try.

Updating from inside Blender

From 1.5.3 onward the addon can update itself without going through the app. In Blender, open Edit → Preferences → Add-ons → Action Library and use the Updates section to check for and install a new release. It backs up your current addon before replacing it.

This updates the addon only — not the desktop app. The two are separate downloads. Updating the addon from Blender leaves the app at whatever version you installed, and the app will keep reporting that older version. To update the app itself, download it from the releases page and install it as usual.

If the two drift apart, the Action Library panel in Blender's N‑panel tells you which half is behind — whether the addon needs reinstalling from the app, or the app itself needs downloading. They ship together, so it's worth keeping them on the same version.

When it doesn't work

"Installation failed"

The app couldn't drive Blender. Check the Path points at the real Blender executable (blender.exe, not a shortcut or the installer), and press Verify — it must report a version. If Blender is installed somewhere needing admin rights, try running Action Library as administrator once, just for the install.

Blender starts, but there's no Animation Library panel

  • Is the sidebar open? Press N in the 3D Viewport.
  • Are you on the Animation tab? It's easy to miss — the tabs are vertical text along the right edge.
  • Was Blender open during the install? Close it and install again.
  • Check Edit › Preferences › Add-ons and search for Action Library. It should be listed and ticked. If it's listed but unticked, tick it — then tell us, because the installer is supposed to do that for you.

The addon is there, but nothing reaches the app

The addon and the app talk over a local port, which must match on both sides. In Action Library it's under Settings › Blender Integration › Port; in Blender it's in Edit › Preferences › Add-ons › Action Library. They both default to 9876. If you changed one, change the other.

If a capture doesn't appear in the app straight away, give it about five seconds — the app checks for new captures on a short timer. It will also pick anything up on the next refresh.

The addon points at the wrong library

The app owns the library location and the addon follows it automatically, within a couple of seconds — you shouldn't have to set it in Blender at all. The path shown in the addon's preferences is a mirror of the app's setting, which is why it's greyed out. If it ever looks stale, press the refresh button next to it.

Still stuck

Action Library keeps a log. Open the console icon in the header to see what it recorded during the install — the error is usually in there in plain English.
