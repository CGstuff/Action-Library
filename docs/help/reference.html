PoseA single frame.
ArmatureBlender's skeleton — the rig you apply animation to.
Rig typeA label for which rig an animation was built for.
Library / storage folderThe folder holding all your animations.
VersionOne take of an animation. Same name = new version.
LatestThe version currently shown in the grid.

SlotBlender 4.5+ — several animations on one layered action.
DrawoverA drawing on a frame of a preview, for review.
TagA free-form label you can search and filter by. Each folder also tags its animations with its own name.

Troubleshooting

The addon isn't in Blender

Close Blender, reinstall from Settings › Blender Integration, start Blender. Full details: Install & update.

I captured something and it's not in the library

Wait five seconds, then press refresh. If it's still missing, check that the addon's library path matches the app's — the addon panel shows the path it's using.

Applying does nothing

Select an armature in Blender first. If you get a connection error, Blender must be running with the addon enabled and the port must match on both sides.

My folder looks empty

Check the header — a search or a rig-type/tag filter narrows what's shown inside a folder too, so a filter left on from earlier can empty it. Also check the recursive toggle in the folder tree: with it off, you see only that folder's own animations, not its subfolders'.

Renaming a folder is safe and won't empty it — what's in a folder doesn't depend on what it's called.

A colleague's animation isn't showing up

Give it a few seconds, then refresh. If it takes minutes, or things appear much later than they should, check you're on a real network share and not a cloud-sync folder — see Sharing a library. Also make sure everyone's running the same version of Action Library.

Empty Trash doesn't delete anything

Allow permanent deletion is off by default, under Settings › Storage Locations.

The status badge won't change

You're probably in Pipeline mode, where Pipeline Control owns status. Check Settings › Operation Mode.

The library looks wrong or things are missing

Try Settings › Maintenance › Rebuild Database. It throws away the index and rebuilds it from your actual files, which are the truth. Your animations aren't touched.

Something else

The console button in the header shows what Action Library has recorded. The error is usually in there in plain English, and it's the most useful thing to include if you report a problem.
