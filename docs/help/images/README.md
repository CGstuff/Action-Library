# Documentation images

Screenshots and GIFs for the docs. Referenced relatively from the HTML pages:

    <img src="images/capture_panel.png" alt="The Capture panel in Blender">

Guidelines:
- PNG for UI screenshots, JPG for photo-ish content, GIF for short motion.
- Keep them reasonably sized - these ship with the app.
- Always write real alt text; it's what a reader gets if the image fails.
